# QBuild Bouwscroll

Originele website-export van het [Claude-artifact](https://claude.ai/artifact/P8fADgx6Ua15XMna2RxieN), gedownload op 29 oktober 2026.

## Lokaal starten

Geen installatie of build nodig. Start vanuit deze map:

```sh
python3 -m http.server 8000
```

Open vervolgens http://localhost:8000.

## Bestanden

- `index.html`: complete website, inclusief CSS, JavaScript en 96 ingebedde animatiebeelden.
- `frames/`: aanvullende beelden uit de oorspronkelijke ZIP-export. De huidige pagina gebruikt de ingebedde beelden.

Google Fonts wordt extern geladen. Er is geen backend. De gespreksoproep is in het originele concept gewone tekst, zonder formulier of boekingslink.

## Exportopmerking

De originele export bevat een leeg aanvullend bestand `frames/f020.webp`. Dit heeft geen invloed op de huidige website: het ingebedde animatiebeeld 20 is wel aanwezig. De oorspronkelijke export is ongewijzigd bewaard.
